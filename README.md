# LLD Learning Roadmap

What I want to learn, in order.

## Phase 1: Object-oriented fundamentals

- Structs and methods
- Interfaces
- Composition
- Encapsulation
- Polymorphism
- Dependency inversion
- SOLID principles

## Phase 2: Design patterns

Learn these through actual problems:

- Strategy
- Factory
- Observer
- Decorator
- Adapter
- State
- Command
- Singleton

## Phase 3: LLD problems

Implement:

1. Parking Lot
2. Splitwise
3. Elevator System
4. ATM
5. Library Management
6. Food Ordering System
7. Movie Ticket Booking
8. Logging Framework

## Phase 4: Real-world engineering

Move beyond class diagrams.

Build:

- A concurrent job scheduler.
- A rate-limiting service.
- A notification system.
- A simple message broker.
